# Godot 魔方项目
基于 **Godot 4.x** 开发的 3D 魔方演示项目，包含多层魔方模型、场景界面、开始/退出交互、3D 相机视角、UI 菜单系统。

## 项目简介
本项目使用 Godot 引擎原生 3D 节点搭建魔方几何体，实现了多尺寸魔方堆叠场景、主菜单界面交互、游戏场景加载、窗口适配、鼠标样式、程序退出等基础功能。
后续可拓展魔方旋转逻辑、打乱还原算法、魔方层位控制、按键操作等完整魔方玩法。

- 游戏引擎：**Godot 4.x**
- 开发语言：GDScript 4
- 渲染：原生 3D 实时渲染
- 界面：2D UI 菜单、按钮交互、场景切换管理

## 项目功能
- 精美 3D 魔方场景与多阶魔方模型展示
- 主菜单：**开始游戏**、**退出游戏**按钮交互
- 场景加载与场景间变量管理
- 窗口自适应、相机视野适配
- 鼠标光标样式控制
- 程序正常退出功能
